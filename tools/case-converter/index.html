      About the Case Converter

      Retyping text because Caps Lock was on, or fixing headings that use inconsistent capitalisation, is tedious. Paste your text, choose a format, and copy the result. Line breaks are preserved, so you can convert lists or many lines at once.

      How to use the Case Converter

      1. Paste or type the text you want to convert into the first box.
      2. Click the format you want, such as Title Case or snake_case.
      3. Review the converted text in the result box. If you edit the original text, the result updates in the same format.
      4. Click Copy result or download it as a text file.

      Example use cases

      • Fixing text that was typed with Caps Lock on by mistake.
      • Formatting article headings and email subject lines consistently in Title Case.
      • Turning a phrase into a variable, function or file name (camelCase, snake_case, kebab-case).
      • Converting a list of names or product titles to a single style.
      • Creating URL slugs from page titles using kebab-case.

      Which case should I use?

      • Title Case capitalises the main words and keeps short words such as “a”, “and”, “of” and “the” lowercase (except at the start or end). Style guides differ slightly, so review important headlines.
      • Sentence case capitalises only the first letter of each sentence and the word “I”. It is common for UI text and modern headings. Proper nouns such as names and places will need to be re-capitalised by hand.
      • camelCase and PascalCase are used for variable and class names in languages such as JavaScript, Java and C#.
      • snake_case is common in Python and databases; CONSTANT_CASE is used for constants; kebab-case is used in URLs and CSS class names.

      Frequently asked questions

      Will Sentence case keep names capitalised?

      No. The tool cannot tell which words are names or places, so it lowercases everything except the start of each sentence and the word “I”. Re-capitalise proper nouns after converting.

      Does the converter keep my line breaks?

      Yes. Each line is converted separately and the line breaks stay where they were. For camelCase, snake_case and similar formats, each line becomes one identifier.

      Does it work with accented and non-English letters?

      Yes. Letters such as é, ß, ç and Cyrillic or Greek characters are converted using your browser’s built-in Unicode case rules.

      Is there a limit to how much text I can convert?

      There is no fixed limit. Very large texts (several megabytes) may take a moment, depending on your device.

      Is my text private?

      Yes. Conversion happens entirely in your browser and nothing is uploaded or saved.
