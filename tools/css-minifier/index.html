      CSS Minifier

      Shrink your stylesheets by removing comments, line breaks, indentation and other characters browsers don’t need. See the size before and after, then copy or download the minified CSS.

      Runs in your browser — your data is never uploaded or stored.

      About the CSS Minifier

      Smaller CSS files download faster, which helps pages render sooner — especially on mobile networks. This minifier safely protects strings and keeps important licence comments if you want them.

      How to use the CSS Minifier

      1. Paste your CSS into the input box, or click Load sample to see an example.
      2. Choose whether to keep licence comments that begin with /*!.
      3. Click Minify CSS and check the size savings.
      4. Copy the minified CSS or download it as styles.min.css. Keep your original file for future edits.

      Example use cases

      • Reducing stylesheet size before deploying a website.
      • Shrinking CSS for HTML email templates or embedded widgets.
      • Quickly compressing a single file without setting up a build tool.
      • Comparing how much whitespace and comments add to a stylesheet.

      Frequently asked questions

      Will minifying change how my site looks?

      It shouldn’t. The minifier only removes comments and whitespace that browsers ignore, plus redundant semicolons and empty rules. Spaces that matter, such as in calc(100% - 2rem) or between selectors, are kept. Always test before deploying.

      Does it do advanced optimisations?

      No. It does not merge rules, shorten colours or restructure your CSS. Build tools such as cssnano or Lightning CSS can achieve slightly smaller output for production pipelines.

      How much smaller will my CSS be?

      Typically 15–40%, depending on how many comments and how much indentation your file has. Server compression (gzip or Brotli) reduces the transfer size further.

      Is my code uploaded?

      No. Minification runs in your browser.
