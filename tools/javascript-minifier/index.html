      JavaScript Minifier

      Make JavaScript files smaller by removing comments, indentation and unnecessary line breaks. The minifier preserves strings, regular expressions and template literals, and checks that the result is still valid code.

      Runs in your browser — your data is never uploaded or stored.

      About the JavaScript Minifier

      This is a safe, lightweight minifier that removes comments and whitespace only — it does not rename variables or rewrite your code. That makes it predictable for quick tasks such as snippets, bookmarklets and small scripts.

      How to use the JavaScript Minifier

      1. Paste your JavaScript into the input box, or load the sample.
      2. Choose whether to keep licence comments that start with /*!.
      3. Click Minify JavaScript. The tool removes comments and whitespace, then runs a syntax check.
      4. Copy or download the result, and test it before using it in production.

      Example use cases

      • Shrinking small scripts and snippets embedded in web pages.
      • Creating bookmarklets, which need code on a single compact line.
      • Reducing the size of widgets or analytics snippets you share with others.
      • Quickly removing comments from code before sharing it.

      What this minifier does — and doesn’t — do

      It removes comments, collapses whitespace and drops line breaks wherever doing so cannot change how the code runs. Line breaks are kept where JavaScript’s automatic semicolon insertion depends on them (for example after return), so code that relies on optional semicolons keeps working.

      It does not rename variables, remove unused code or transform modern syntax. For full production builds, tools such as Terser, esbuild or SWC produce much smaller output. JSX and TypeScript are not supported — compile them to JavaScript first.

      Frequently asked questions

      Is the minified code guaranteed to work?

      The tool only removes characters that don’t affect behaviour and checks the result with your browser’s JavaScript parser (without running it). A rare edge case, such as a regular expression directly after a closing bracket, could still trip it up, so always test minified code.

      Does it support ES modules (import/export)?

      Yes, the code is minified in the same way. However, the automatic syntax check is skipped for module code, because browsers can only check modules when loading them.

      Why is the saving smaller than with other minifiers?

      Advanced minifiers also shorten variable names and rewrite expressions. This tool deliberately avoids that so your code stays readable and predictable.

      Is my code uploaded or executed?

      Neither. Your code is processed in your browser and is never sent anywhere. The syntax check compiles it without running it.
