      About the Character Counter

      Many places limit text by characters rather than words: social media posts, SMS messages, page titles, form fields and database columns. This tool counts emoji and accented letters as single characters, as people see them, and also shows the UTF-8 byte size that matters for developers.

      How to use the Character Counter

      1. Paste or type your text into the box. All counts update as you type.
      2. Optionally choose a limit — for example an X (Twitter) post or SMS message — or set your own custom number.
      3. Use the progress bar to see how many characters remain, or how far over the limit you are.
      4. Shorten your text as needed, then copy it back to where you need it.

      Example use cases

      • Writing social media posts that fit within a platform’s character limit.
      • Keeping SMS marketing messages within a single 160-character segment.
      • Drafting page titles and meta descriptions that are less likely to be cut off in search results.
      • Checking that input fits a database column or form field with a maximum length.
      • Counting characters for translation, subtitles or captions.

      Frequently asked questions

      Do spaces count as characters?

      Yes, in most systems spaces count toward a character limit. This tool shows the total both with and without spaces so you can use whichever you need.

      How are emoji counted?

      Each emoji is counted as one character, even if it is made of several code points (such as a family emoji or a flag). Some platforms count emoji differently — for example, X (Twitter) counts most emoji as two characters.

      Is this exactly how X (Twitter) counts characters?

      Not exactly. X counts every link as 23 characters and counts some characters, such as Chinese, Japanese, Korean and most emoji, as two. Use the 280 limit here as a close guide and check the counter in the app before posting.

      Why does an SMS limit of 160 sometimes become 70?

      Standard SMS uses a basic character set that fits 160 characters. If your message includes an emoji or a character outside that set, the whole message switches to Unicode and the limit drops to 70 characters per segment.

      What are bytes and why would I need them?

      Bytes measure how much storage the text uses. In UTF-8, basic English letters use one byte each, while accented letters, symbols and emoji use two to four. Developers use byte counts for database limits and network payloads.
